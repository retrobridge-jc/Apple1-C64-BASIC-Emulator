# Contributing

Contributions are welcome.

This project is intentionally educational and BASIC-first. Useful contributions include:

- Opcode fixes or compatibility improvements
- Additional trace/debugging features
- Performance improvements that preserve the BASIC implementation
- Documentation improvements
- Tests with additional Apple-1 software
- Original Commodore 64 hardware testing

## Third-party software

Please do not submit pull requests that add WozMon, Apple Integer BASIC, or other third-party software binaries to this repository.

If a test requires third-party software, document the requirement and the expected filename rather than committing the software itself.

## Source changes

When changing the emulator, please describe:

1. What changed
2. Why it changed
3. How you tested it
4. Whether it changes compatibility, memory mapping, or expected filenames

If possible, keep the plain-text BASIC source and the loadable PRG synchronized.
